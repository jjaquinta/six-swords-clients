# Fair use

Six Swords is run by one person, on a small server, for free. Clients are very welcome; please keep
it that way for everyone.

- **One player, one ID.** Don't create players in bulk. There is a limit of 20 new players per
  address per hour, and clients that hit it routinely will be blocked.
- **People, not robots.** Send turns because a player asked for them. No scraping, mapping bots or
  automated play without asking first (open an issue).
- **One turn at a time.** Wait for a reply before sending the next turn for the same player.
- **Keep player IDs private.** An ID is the player's only key to their character.
- **The game's content stays the game's.** Show and speak the replies to your players; don't
  republish the game's text, sounds or world in other works. The API docs and example code are
  openly licensed; the game is not.
- **Name it as yours.** Make clear that your client is your own work and not the official one.

Access may be limited or withdrawn for clients that cause problems. If you're unsure whether
something is fine, open an issue and ask.
